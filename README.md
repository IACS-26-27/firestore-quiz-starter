# Get to Know the Class

Hello friends. In the weather project, you used `fetch` to *read* data from
someone else's server. This time you'll read *and* write data, in a database
your whole group shares. You'll answer a quiz, save your answers, and then
see everyone else's answers show up on your page.

I've already set up the database (it's called Firestore, and it's made by
Google), so you don't need to set anything up.

## Steps

Do these in order. Each one adds a little to [`index.html`](index.html) and
[`app.js`](app.js).

0. [How Firestore organizes data](steps/0-documents-and-collections.md)
1. [Get the quiz from the database](steps/1-get-the-quiz.md)
2. [Show the questions on the page](steps/2-show-the-questions.md)
3. [Sign in](steps/3-sign-in.md)

5. [See everyone's answers](steps/5-see-everyones-answers.md)
6. [The rules of the road](steps/6-rules-of-the-road.md)

## Before you start

- Start Live Server, same as always, and open the page. It's blank. That's
  on purpose: you're building it.
- Open dev tools (right-click → "Inspect") and click the "Console" tab.
  Keep it open the whole time.

## Publishing

Turn on GitHub Pages: "Settings" → "Pages" → under "Source" pick "GitHub
Actions". After that, every push publishes your site.
